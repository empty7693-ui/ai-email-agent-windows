# Email Agent for Windows — AI Email Automation

Automate routine replies to incoming customer emails from your existing mailbox. **Email Agent** connects over IMAP, sends replies over SMTP and uses the AI model and instructions that you configure.

> Email Agent is a ready-made commercial Windows application, not an open-source email library or a source-code repository. This repository provides product information and links to the official website.

## Overview

Email Agent runs on your Windows PC and works with a mailbox you already use. It reads incoming messages, considers the relevant conversation context and prepares and sends replies according to your assistant role, rules and conversation stages.

It is designed for incoming correspondence and routine one-to-one conversations, not bulk email campaigns.

## Main features

- Read incoming mail through **IMAP** and send replies through **SMTP**.
- Configure an AI model through an OpenAI-compatible API.
- Define the assistant's role, writing style, rules and conversation stages.
- Keep conversation history in a local application database.
- Follow the language of the latest substantive message.
- Group consecutive incoming messages before replying.
- Configure working hours and per-contact, hourly, daily and conversation limits.
- Take over a thread manually; the agent can stay silent in that conversation.
- Configure proxy access for network connections.
- Use built-in mailbox presets for Gmail, Yandex, Mail.ru, Outlook, iCloud, Yahoo and Zoho, or enter another provider manually.

## How it works

1. Connect your existing mailbox using its IMAP and SMTP settings.
2. Enter the API key, endpoint and model for your chosen AI provider.
3. Define the assistant's role, rules and conversation stages.
4. Configure sending limits and working hours.
5. Test the connections and start the agent.
6. Monitor conversations and take over whenever a human response is needed.

## Requirements

- Windows 10 or Windows 11.
- A mailbox with IMAP access for reading and SMTP access for sending.
- An API key and model endpoint from an AI provider offering an OpenAI-compatible API.
- A compatible proxy configured in the application for network access.
- Internet connection.

The PC and application must remain running and online for automatic replies. The software does not process messages while the computer is off. AI-provider usage is billed separately by that provider.

## Privacy and responsible use

Conversation data is stored locally on your PC. The message content needed to generate a reply is sent to the AI provider whose API key you configure; it is not routed through Message-Assistent mail servers. Review your provider's privacy terms and your own mailbox/security settings before enabling automatic sending.

Use sensible sending limits and review your assistant's instructions before leaving it unattended. You remain responsible for messages sent from your email address and for compliance with applicable privacy and anti-spam rules.
